# CPINN reproduction: official-code authority

## Maintainer decision

For the Poisson and Burgers reproduction, the executable examples in the official CPINN repository are the source of truth. When the paper, appendix, comments, or prose disagree with executable code and its bundled data, follow the code and data. Do not create a hybrid paper/code protocol or silently replace a surprising implementation with an inferred intended algorithm.

This document fixes the reproduction policy. It does not itself change the released examples, implement a new compatibility solver, or establish new convergence results.

## Frozen reference

- Repository: `comp-physics/CPINN`.
- Commit: `ef0d6a4504e5a5fd69e3d0583f4c821b33436c2d`.
- Poisson entrypoint: `Poisson/train_1Dis_GACGD.py`, with `Poisson/networks.py` and `Poisson/utils.py`.
- Burgers entrypoint: `Burger/BurgerTrainGACGD.py` and the bundled `Burger/burgers_shock.mat`.
- Optimizer and sampling distributions named in the official requirements: `CGDs==0.4.5`, `pyDOE==0.3.8`. Use their frozen distribution files, not an unpinned current Git branch.
- Comparison target: the audited `jax-cgd==2.0.0rc1` source `df67eb6c6309014b6c2752cfadd59a7483c181b2`.
- Existing line map and executed audit evidence: `CPINN_OFFICIAL_PARITY_AUDIT.md` and `CPINN_OFFICIAL_PARITY_RESULTS.json` in this directory. Those results predate this decision; no new test is claimed here.

## Burgers details that must not be silently changed

1. Derive the coordinate bounds from the bundled data. The audited reference has `t.max()=0.99`; do not generate a new endpoint of 1.0.
2. Normalize primal inputs using the actual bounds; the time transform is `2*t/0.99 - 1`. The discriminator receives raw `(x,t)`.
3. Preserve the discriminator's shared middle layer. For the README's 8x60 discriminator, there are 3,962 unique parameters, not the 25,922 of the previously added independent-layer Flax example.
4. Preserve objective directions after translating player order. In the official script, `C=mean(D_bc*(g-u))+mean(D_pde*r)` and the D-first optimizer receives `step(C,-C)`. In JAX's min-P/max-D convention, use `f=-C`, or an explicitly verified equivalent output-channel parameter transformation. Do not change only a sign without accounting for the initial tensors.
5. Preserve initialization order and export the actual starting tensors. The Burgers script does not completely specify the discriminator's initial RNG state before construction. Record the state used in a controlled reference execution and share its tensors with JAX; do not claim it recovers the authors' unpublished historical initialization.

## Shared data and initial state

Export actual arrays from the frozen official sampling routines, including indices, targets, bounds and evaluation grids. Export actual initialized Torch weights and biases and map them to Flax with documented transpose and parameter-sharing rules. Store hashes and environment versions. Matching integer seeds in Torch and JAX is not an alignment criterion.

Run the official reference before interpreting a JAX training outcome. Equal architectures in prose or equal parameter counts alone are insufficient. Verify forward outputs, PDE and boundary residuals, scalar game, both gradients, both mixed HVPs, adaptive moments, learning-rate vectors, and parameter updates from identical states.

## Solver fidelity and work accounting

The strict official-code reference uses the actual CGDs 0.4.5 behavior: a full block system, cold starts, non-restarted GMRES, and each script's iteration-cap semantics. Poisson explicitly supplies `max_iter=1000`; Burgers leaves it at the dependency default, which must not silently be replaced with 1,000 or with a restart-cycle count.

Reference fidelity includes the dependency's small-RHS shortcut and its zero-based `num_iter` return. A strict compatibility path must retain these behaviors or declare its deviation. A second, observational diagnostic may record the true residual and actual Arnoldi/matvec counts without changing the reference update or stopping decision. Do not call the historical index a measured number of iterations or of AD passes.

This does not require weakening the public package's safe defaults. Keep the original reference or an explicitly named compatibility adapter separate from the general-purpose guarded solver. If guard rejection changes a trajectory relative to the reference, report it as a protocol difference rather than claiming exact reproduction.

Schur-CG, warm starts, restarted GMRES and exact spatial-jet acceleration belong to a separately labelled optimized variant until numerical and trajectory comparisons establish their effect. The strict baseline must not combine them silently with historical settings.

## Acceptance and reporting

First compare the official-code execution and the aligned JAX execution on identical frozen data and starting arrays. Establish single-state and short-trajectory parity before a hundreds-of-steps and full-script-length comparison. Predeclare tolerances and retain intermediate diagnostics; do not loosen them after seeing results.

Record training error curves, accepted/attempted updates, reference-reported indices, actual work counts, true residuals, wall time and stop reason separately. Evaluate both frameworks on exactly the same reference grid. Paper plots remain contextual published results, not authority for overriding code settings. Agreement with an official-code run and recovery of the published final accuracy are separate claims.

Modern-runtime compatibility changes, when required to execute historical code, must be minimal, logged and numerically checked. Do not claim reproduction of the historical runtime when using a newer Torch/JAX/CUDA stack.

## Current status

Policy frozen on the audit branch only. Existing short-parity results remain as previously reported. No new training was performed by this documentation change; no main merge, package-source change, or PyPI upload is part of it.
